# ⚽ Controle de Figurinhas - Copa do Mundo 2026

App web para controlar sua coleção de figurinhas do álbum Panini da Copa do Mundo FIFA 2026.

## 🔗 Acesse o app

👉 **[Abrir o app](https://joaov-nunes.github.io/figurinhas-copa-2026/)**

## ✨ Funcionalidades

- **994 figurinhas** catalogadas — 48 seleções em 12 grupos (A–L), seções especiais FWC e CC
- **Gráfico circular** de progresso em tempo real
- **Clique simples** para marcar figurinha como "tenho" / **duplo clique** para marcar como repetida
- **Filtros rápidos** — Todas, Faltantes, Coladas e Repetidas
- **Busca** por código ou nome do país
- **Contador de repetidas** com quantidade de cópias extras por figurinha
- **Backup e restauração** em JSON para não perder o progresso
- **Geração de PDF** com lista de faltantes e repetidas, pronto para compartilhar e combinar trocas
- **Salva automaticamente** no navegador (localStorage)

## 📱 Como usar

1. Abra o arquivo `index.html` no navegador (ou acesse o link acima)
2. Clique em uma figurinha para marcar que você já tem
3. Dê duplo clique para definir quantas cópias repetidas possui
4. Use os filtros para ver só as faltantes ou repetidas
5. Gere o PDF para compartilhar sua lista de trocas
